# Guia breu: abans de substituir un dispositiu

Una activitat de reflexió per a l'aula:

1. Descriu el problema del dispositiu.
2. Comprova si una actualització, neteja o reparació el pot resoldre.
3. Busca una opció de reutilització abans de reciclar-lo.
4. Anota quines dades cal esborrar abans de lliurar-lo.
